# [[ .Repo ]]

Warden service **[[ .Name ]]**, generated by `warden new` (owner: [[ .Owner ]]).

Merging to `main` builds, scans, signs and attests the image in Warden's platform workflow, then promotes its
digest to `warden-gitops`. The cluster admits it only if the signature and provenance verify, and rolls it out
as a canary judged by Prometheus.

```bash
./mvnw verify          # tests (JDK 25)
./mvnw spring-boot:run # http://localhost:8080/api/info
```

Endpoints: `/api/info`, `/api/items`, `/actuator/health`, `/actuator/prometheus`.

To ship a deliberately faulty release for the rollback experiment, change `warden.demo.error-rate` or
`warden.demo.latency-ms` in `src/main/resources/application.yaml` and merge.
